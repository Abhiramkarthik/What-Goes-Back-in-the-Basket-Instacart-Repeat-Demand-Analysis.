# Product demand by day code and hour

Values are product-order rows from prior orders. Day codes remain numeric because the weekday mapping has not been verified.

- Highest-volume window: day code 0, 14:00 — 564,896 product-order rows across 50,484 orders.
- Lowest-volume window: day code 3, 03:00 — 5,777 product-order rows across 605 orders.

See `product_lines_by_day_hour.csv` for the full table and `product_lines_day_hour_heatmap.png` for the heatmap.

This describes historical order activity. The data does not include inventory levels or stockout events.
